Beginner or Advanced?

Beginner shows only what a normal home or shop needs: internet, ports, Wi-Fi and an admin login. Advanced adds backup ISP, port forwarding, speed limits and custom names. Switch any time at the top.

Before you start

Have these ready: how your ISP connects you (PPPoE username and password, a fixed IP, or automatic), and which port goes to the ONU or modem. Beginners: leave everything else on its default.

Internet

How does your ISP give you internet?

Nothing to fill in. The router asks the ONU or ISP for its address.

Which one do I have?

PPPoE: the ISP gave you a username and password. Static IP: the ISP gave you an IP, gateway and mask. DHCP: you just plug in and it works. The gateway must sit in the same network as your IP, and the tool checks that.

Backup ISP (failover)

In Ports, set one port to "Backup ISP". If the main internet link drops, the router switches to it.

What is a LAN and a bridge?

A LAN is a private network. A bridge joins several ports into one LAN so they act like one switch. Each LAN has its own router IP, for example 192.168.10.1/24, and the router hands out addresses from that range. Pick different networks for each LAN.

Router login

Create your own admin so you never keep the default one.

Why change the admin?

Every MikroTik ships with the same "admin" user. Attackers try it first. Your own name plus a strong password is much safer.

Port forwarding

Let people on the internet reach a device inside your LAN, such as a camera or web server. One rule per line: protocol,external port,internal IP,internal port,name

It does not work from outside?

Some ISPs share one public IP between many customers (CGNAT). Then port forwarding cannot work. Ask the ISP for a public IP.

Your script

Check the list below, copy the script, then follow the steps.

    How to apply it

    1. Back up. In WinBox open Files, then Backup. Or run /system backup save.
    2. Reset to empty. Run /system reset-configuration no-defaults=yes skip-backup=yes. The router restarts.
    3. Connect a LAN port. Plug your computer into a port you set as LAN, not the ISP port. Open WinBox, choose the Neighbors tab, connect by MAC address.
    4. Paste. Open New Terminal, paste the script, press Enter.
    5. Plug in the ISP cable to the ISP port and run the checks below.
    Check that it works
    • IP, then Addresses: your LAN IPs are listed.
    • PPPoE mode: Interfaces shows pppoe-out1 with an R (running).
    • Run /ping 8.8.8.8 count=3 and then /ping google.com count=3. If only the second fails, it is a DNS problem.
    • IP, then DHCP Server, then Leases: your devices appear.
    Troubleshooting
    • No internet with PPPoE: check username and password, and that the ISP port is the one going to the ONU.
    • Locked out: hold the reset button, or use Netinstall. Always back up first.
    • Wi-Fi not showing: check the interface name under Interfaces. RouterOS 7 often uses wifi1.
    • Script error in the middle: reset to empty and paste again. The script expects a clean router.
    Glossary
    • WAN: the side facing the internet.
    • LAN: your private network inside.
    • Gateway: the address your traffic leaves through.
    • Prefix (/24): the size of a network. /24 holds 254 devices.
    • NAT: lets many devices share one public IP.
    • DHCP: hands out addresses automatically.
