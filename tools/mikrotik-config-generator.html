MikroTik advanced config generator

RouterOS script builder with SFP ports, up to 4 LANs, WAN VLAN, speed limits and hardening. Set everything, then press Generate.

1. Internet (ISP) mode

The router gets IP, gateway and DNS from the ONU or ISP automatically.

Second ISP (WAN 2) for failover

Optional. In step 2, set one port to WAN 2. If the main internet link fails, the router switches to this one. Static mode also pings the gateway to spot a dead link. DHCP and PPPoE switch when the link goes down.

2. Port assignment

Use Trunk (VLAN tagged) for the port that goes to a managed switch or access point carrying your VLANs.

3. LAN networks

Speed limit 0 means no limit. Limits are in Mbps and apply to the whole LAN.

Port forwarding (open a service to the internet)

One rule per line: protocol,external port,internal IP,internal port,name. Internal port and name are optional. Example: tcp,8080,192.168.10.50,80,web-server

5. Router admin login

Pick Full control to change settings, or Read-only to view settings without changing them. You log in to WinBox with this user.
